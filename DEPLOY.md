# Drip & Coil — публикация в интернете

## Вариант 1: Render + постоянный диск

1. Создай аккаунт GitHub и новый приватный репозиторий.
2. Загрузи содержимое этой папки в репозиторий.
3. В Render выбери **New → Blueprint** и подключи репозиторий.
4. Render увидит `render.yaml`.
5. При создании сервиса задай секрет `ADMIN_PASSWORD` — придумай новый пароль и не публикуй его в GitHub.
6. После Deploy Render выдаст адрес вида `https://drip-and-coil.onrender.com`.
7. Открой сайт с телефона. Админка находится по кнопке ADMIN внутри сайта.

## Что сохраняется
SQLite база находится на постоянном диске `/opt/render/project/src/data`, поэтому товары и заказы не должны исчезать после обычного перезапуска сервиса.

## Telegram

## Перед реальным запуском
- поменять демо-товары на реальные;
- добавить фотографии;
- задать сложный пароль;
- подключить собственный домен при необходимости;
- проверить правила продажи возрастных товаров и не включать их в заказ без необходимых проверок.
