# Drip & Coil — real admin version

## Что это
Полноценный локально запускаемый магазин: каталог, корзина, заявки, Telegram, серверная БД SQLite и защищённая админка.

## Запуск
1. Установить Node.js 20+.
2. Скопировать `ADMIN_PASSWORD.txt` или задать свой пароль через переменную окружения `ADMIN_PASSWORD`.
3. В терминале:
   - `npm install`
   - `ADMIN_PASSWORD="ваш_пароль" TELEGRAM_ADMIN="s88xy" npm start`
4. Открыть `http://localhost:3000`.
5. Админка находится на той же странице в разделе ADMIN.

Для Windows PowerShell:
`$env:ADMIN_PASSWORD="ваш_пароль"; $env:TELEGRAM_ADMIN="s88xy"; npm start`

## Что хранится на сервере
- товары и остатки;
- статусы «В наличии» / «Под заказ»;
- заявки клиентов;
- статусы заказов;
- Telegram администратора.

## Важно для публикации в интернете
Для публичного сайта нужен хостинг и HTTPS. SQLite-папка `data/` должна находиться на постоянном диске либо БД надо заменить на Postgres/Supabase. Пароль администратора задаётся секретом хостинга и не должен попадать в HTML или Git.
